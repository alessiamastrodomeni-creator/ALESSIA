# Creare un link per salvare un evento nel calendario

Certo! Se vuoi che i tuoi amici possano **aggiungere un singolo evento** al loro calendario, puoi creare un link Google Calendar come questo:

```text
https://calendar.google.com/calendar/render?action=TEMPLATE&text=TITOLO&dates=DATA_INIZIO/DATA_FINE&details=DESCRIZIONE&location=LUOGO
```

## Esempio

Evento: aperitivo il 15 giugno 2025, dalle 19:00 alle 22:00 a Milano.

```text
https://calendar.google.com/calendar/render?action=TEMPLATE&text=Aperitivo%20con%20gli%20amici&dates=20250615T170000Z/20250615T200000Z&details=Non%20vediamo%20l%27ora%20di%20vedervi!&location=Milano
```

> Gli orari nell’esempio sono in formato UTC: `17:00Z` corrisponde alle 19:00 in Italia durante l’ora legale.

## Informazioni necessarie

Mandami questi dati e ti preparo direttamente il link:

- **Titolo dell’evento**
- **Data**
- **Orario di inizio e fine**
- **Fuso orario**, se diverso dall’Italia
- **Luogo o indirizzo**
- **Descrizione**
- Eventuale **link per videoconferenza**

## Alternativa: file `.ics`

Se vuoi un link compatibile anche con **Apple Calendar, Outlook e altri calendari**, posso prepararti un file `.ics`. Dovrai poi caricarlo online o inviarlo agli invitati, perché per funzionare come link deve essere disponibile tramite un URL pubblico.

# Dove caricare la pagina HTML

Per ottenere un link pubblico da condividere con i tuoi amici, puoi usare una di queste soluzioni.

## Opzione più semplice: Netlify Drop

1. Salva il file ricevuto con il nome **`index.html`**.
2. Vai su **[app.netlify.com/drop](https://app.netlify.com/drop)**.
3. Trascina il file nella pagina.
4. Netlify genererà automaticamente un link pubblico, ad esempio:
   `https://nome-casuale.netlify.app`
5. Copia e condividi il link su WhatsApp o via email.

**Non serve creare un account** per una prova veloce, anche se Netlify potrebbe chiederti di registrarti per gestire meglio il sito.

## Alternative

### GitHub Pages

Utile se vuoi conservare il file online:

- Crea un account su [GitHub](https://github.com).
- Crea un nuovo repository.
- Carica il file rinominato **`index.html`**.
- Attiva **Settings → Pages**.
- Otterrai un indirizzo simile a:
  `https://tuonome.github.io/nome-repository/`

### Vercel

Puoi caricare il progetto anche su [vercel.com](https://vercel.com), ma è leggermente più tecnico rispetto a Netlify.

## Importante

Servizi come **Google Drive, Dropbox o WhatsApp** generalmente non mostrano il file HTML come una vera pagina web: spesso lo fanno scaricare.

Per il tuo caso ti consiglio **Netlify Drop**: è il metodo più rapido per trasformare la schermata con gli hamburger in un link condivisibile.

> Prima di pubblicarlo, verifica anche l’anno dell’evento: il file attuale imposta automaticamente il **prossimo 16 novembre**.

# Siti gratuiti per caricare un file `.ics`

## **1. Netlify Drop — il più semplice**

Puoi ottenere un link pubblico senza configurazioni complicate.

1. Crea una cartella.
2. Inserisci il file `.ics` nella cartella.
3. Rinominalo, ad esempio, `cocktail-party.ics`.
4. Vai su [Netlify Drop](https://app.netlify.com/drop).
5. Trascina la cartella nella pagina.
6. Copia il link generato e condividilo.

Il link sarà simile a:

```text
https://nome-casuale.netlify.app/cocktail-party.ics
```

## **2. Google Drive**

1. Carica il file `.ics` su [Google Drive](https://drive.google.com).
2. Clicca con il tasto destro sul file.
3. Seleziona **Condividi**.
4. Imposta **Chiunque abbia il link**.
5. Copia e invia il link.

È comodo per far scaricare il file, ma **non è ideale per iscriversi a un calendario**, perché Google Drive può mostrare una pagina di anteprima invece del file diretto.

## **3. Dropbox**

1. Carica il file su [Dropbox](https://www.dropbox.com).
2. Clicca su **Condividi** → **Copia link**.
3. Invia il link agli invitati.

Anche Dropbox è adatto soprattutto al **download del file**.

## **4. GitHub Pages**

È gratuito e più stabile, ma richiede qualche passaggio in più:

- crea un repository su [GitHub](https://github.com);
- carica il file `.ics`;
- attiva **Settings → Pages**;
- condividi l’URL del file.

## La mia raccomandazione

Per il tuo caso sceglierei **Netlify Drop**: è rapido, gratuito e ti permette di ottenere un link diretto al file `.ics`.

Se vuoi solo inviarlo agli amici, puoi anche allegare direttamente il file su **WhatsApp o email**, senza caricarlo su un sito.
